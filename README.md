# PARMIBAR — Crafted in Italy. Reimagined in Dubai.

Single-page brand showcase website for PARMIBAR, a luxury Parmigiano Reggiano DOP brand for the GCC market.

## What's inside

- **Brand story** — 800 years of Parmigiano Reggiano provenance
- **Why Parmigiano** — the six pillars: DOP protection, crystalline structure, protein density, no additives, artisan breaking, unchanged tradition
- **Product range** — Protein Platter, Protein Sticks, Snacking Cubes, Olive & Parmigiano Platter
- **Subscribe & Save** — Essential / Reserve / Connoisseur tiers
- **Live order table** — quantity controls, running total, free delivery threshold

## Tech

Pure HTML/CSS/JS — zero dependencies, zero build step. Open `index.html` directly in any browser or deploy to GitHub Pages in one click.

## Deploy to GitHub Pages

1. Go to your repo → **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / `root`
4. Save — your site will be live at `https://YOUR-USERNAME.github.io/parmibar-site/`

## Customise

- **Prices** — search for `AED` in `index.html`
- **Brand name** — search/replace `PARMIBAR`
- **Product photos** — replace the `data:image/jpeg;base64,...` src values with real image URLs once hosted
- **Order flow** — the `submitOrder()` function in the `<script>` block is where you'd connect a real payment or WhatsApp flow
